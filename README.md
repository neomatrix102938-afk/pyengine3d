# pyengine3d
this is my 3dengine built on python and it works in terminal.there's also game with engine and u can write your games
the engine uses only libraries that contain vanilla python 
to run engine:
1. enter engine folder
2. 2. enter in folder 3dengine
3. run terminal inside it
4. run "python engine.py" if u are on Win
5. run "python3 engine.py" if u are on Linux/macOS

2. enter "games (u can create your own)"
3. run terminal inside folder
4. run "python/python3 your_game
